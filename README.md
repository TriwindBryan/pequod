# Pequod

**The emulator launcher that drops you right in.**

Pick your games folder and press Play. Pequod sets up the emulators from their official sites, sorts your games by console with cover art, and gets your controller working, so you don't have to.

**[Download the latest version for Windows](../../releases/latest)**

- Windows 10 and 11. Mac is planned.
- Free. No account, no ads.
- Windows may say "Windows protected your PC" because Pequod isn't code-signed yet. Click More info, then Run anyway.

Pequod includes no games, and no BIOS, firmware or keys from Nintendo, Sony, Sega or Microsoft. Use files from consoles you own. Pequod is not affiliated with any of them.

This repository hosts Pequod's releases and website. Pequod's source code is not public.
