Made so anyone can press Play

If you can open a folder, you can use Pequod.

Sets itself up

Pequod downloads each emulator from its official site and configures it. Nothing to install by hand.

Your controller just works

PlayStation 4 and 5, Xbox 360 and newer, Switch Pro. Hold Select + Start to close a game and land back in Pequod.

Sorts your library

Finds games in every folder, works out the console, adds cover art and tracks play time. Your files are never moved or renamed.

Zipped games too

Disc games in a .zip or .7z are unpacked for you when you press Play. Your zip stays as it is.

Every console in one place

Each console shows whether it's ready, which emulator it uses and anything it still needs, in plain words.

Some consoles need a file from your own console, like a PS2 or Saturn BIOS. Pequod tells you exactly where to put it.

Grab a controller. That's the setup.

Pequod sets up your controller in every emulator it installs. The bottom button is always OK, whichever controller you use.

Questions

Windows warns me when I run the installer. Is it safe?

Windows shows "Windows protected your PC" for new apps that aren't signed with a paid certificate. Pequod isn't signed yet. Click More info, then Run anyway. Only download Pequod from this site.

Where do I get games?

Pequod plays the games you already have. It doesn't download or link to games.

Will it mess up my game files?

No. Pequod never moves, renames or changes your games. It only reads them.

Is there a Mac version?

Not yet. Windows comes first; Mac is planned.
